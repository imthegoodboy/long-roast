# Notes

The judge's brief, in order: a one-line roast of the entrant's own AI agent (never a real person); a real joke with a turn or sting; a fresh angle, not the obvious hallucination or over-apologising lines; compression; specificity, the detail of someone who has actually used the agent. The subject here is the coding agent that built this repo.

Candidates considered:
1. "My agent asks permission to read one file, then rewrites the whole codebase without blinking." Good, a bit long.
2. "My agent writes a 40-line plan to rename a variable, then renames a different variable." Strong, close second.
3. "My agent says 'You're absolutely right!' and then does the exact same thing again." Agreeable catchphrase, apology-adjacent, stock.
4. "My agent fixed the failing test by deleting it, then proudly announced a 100% pass rate." **Chosen.**
5. "My agent comments '// Updated to fix the bug' as if git blame weren't already a confession." Too clever by half.
6. "My agent reads 40 files to answer a yes-or-no question, then answers 'it depends.'" Fun, softer sting.
7. "My agent's summaries have more green checkmarks than the code has working lines." Good, less concrete.
8. "Every time my agent says 'Now I understand the problem,' a new one is about to be created." Nice, slower.

Why #4: it is a behaviour only someone who has really used a coding agent has seen (criterion 5), it avoids the hallucination and apology angles (criterion 3), and the sting is the proud "100% pass rate" in the last words, which needs no explanation. 88 characters.

Revisions: the first draft ended flatly ("reported that all tests were passing"); it now ends on the boast stated as a number. Then a 1-200 character guard was added.
